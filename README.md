# Smart Student Skill & Support Platform (S4P)

## Smart Education | Ideathon 2K26

S4P is a Smart Student Skill & Support Platform designed to help students understand their current skills, identify gaps based on their career goals, create a personalized learning roadmap, and receive mentor support.

Unlike traditional student portals that mainly store student information, S4P focuses on **what a student can do, what they are missing, and what they should learn next.**

---

## Problem Statement

Traditional student portals mainly manage information such as:

- Student registration details
- Course information
- Academic records

However, students often lack a clear understanding of:

- Their current technical skill level
- The skills required for their target career
- Which skills they are missing
- What they should learn next
- When they need mentor support

This can make career preparation difficult and unstructured.

---

## Our Solution

S4P provides a centralized platform that connects:

**Student Profile → Skills → Career Goal → Skill Gap → Learning Roadmap → Mentor Support**

The platform allows students to maintain a Skill Passport, select a career goal, analyze their skill gaps, and receive a prioritized learning roadmap.

Faculty and mentors can monitor students and provide support when needed.

---

## Key Features

### 1. Student Login & Registration

Students can create an account and securely log in to the platform.

### 2. Student Profile

Stores basic student information such as:

- Name
- Email
- Course
- Career Goal

### 3. Skill Passport

Students can record their current skill levels.

Supported levels:

- Beginner
- Intermediate
- Advanced

Example skills include:

- HTML/CSS
- JavaScript
- React
- Node.js
- SQL
- REST APIs
- Git
- Python
- Java
- DSA

### 4. Career Goal Selection

Students can select a target career such as:

- Frontend Developer
- Backend Developer
- Full Stack Developer
- Data Scientist
- Software Engineer

### 5. Skill Gap Analyzer

The platform compares the student's current skill levels with the expected skill levels for their selected career.

The system then:

1. Identifies missing skills
2. Calculates the skill gap
3. Prioritizes larger gaps
4. Displays the results clearly

### 6. Personalized Learning Roadmap

Based on the identified skill gaps, S4P generates a learning roadmap.

Students can see which skills they should focus on first.

### 7. Faculty / Mentor Dashboard

Faculty members can:

- View students
- Monitor student progress
- View student details
- Check support status
- Provide mentor feedback

### 8. My Support

Students can view their current mentor support status and feedback.
